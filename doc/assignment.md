I would like to create a home media center consisting of a server component and a client component.
I have Samba storage with a directory containing movies, various videos, and other media, as well as an Android TV.

I would like a media center where the media source can be configured through Samba access, which will be handled by the server component.
The server will also provide a REST API for a client such as an Android application that communicates with the media center.

The design must account for this media center eventually serving as a smart home assistant, but we will add that functionality
gradually.

For now, I only need it to function as a media center.

Media must be divided by type into videos, pictures and photos, music, MP3 files, and other formats.

The interface must offer simple, understandable choices even for a non-technical user.
